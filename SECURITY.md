# Reporting Security Issues

If you believe you have found a security vulnerability in this project, we
encourage you to let us know right away. We will investigate all legitimate
reports and do our best to quickly fix the problem.

Please refer to the following page for our responsible disclosure policy and to
privately submit a vulnerability report:
